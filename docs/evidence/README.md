# Evidence

Small text records of live checks, published so a clone can read what a document cites as proof. Each is a
point-in-time copy of a record the operator keeps in the ignored `local` tree: what was run, what the panel
read, and what that showed on the day. They are evidence, not statements of current behaviour — the owning
README and the suites state that — and they are not updated when the code moves on.

What is published here is text only: no game data, no screenshots, no saves, and no LAN addresses (replaced by
`<lan-address>`). A new record belongs here when a document cites it; the procedure that produces one is
[`../live-checks.md`](../live-checks.md).
